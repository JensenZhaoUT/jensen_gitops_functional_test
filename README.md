# CES Functional Test App

This repository contains the configuration files for a Customer Engagement Suite (CES) application integrated with GitOps for functional testing.

## Structure
- `app.json`: Root application manifest defining the application display name, description, and root agent.
- `global_instruction.txt`: Global instructions applied across all agents.
- `agents/`: Agent definitions, instructions, model configurations, and tool attachments.
- `tools/`: Tool specifications (client functions, webhooks, or openAPI specifications).
